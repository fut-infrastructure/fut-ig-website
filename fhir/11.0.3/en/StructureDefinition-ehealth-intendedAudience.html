Extension: Intended audience

Official URL: http://ehealth.sundhed.dk/fhir/StructureDefinition/ehealth-intendedAudience Version: 11.0.3
Active as of 2026-10-29 Computable Name: ehealth-intendedAudience

Specifies that the resource is only intended for use in the specified organisations. Leave blank if the resource is intended for global use.

Context of Use

    This extension may be used on the following element(s)

    • Element ID: Element

Usage info

Usages:

  • Use this Extension: ehealth-actionguidance, ehealth-activitydefinition, ehealth-group-appointment, ehealth-group-videoappointment... , ehealth-library, ehealth-plandefinition, ehealth-questionnairelinkage and ehealth-view
  • Examples for this Extension: Appointment/group-appointment01 and Appointment/group-videoappointment01
  • Search Parameters using this Extension: intended-audience
