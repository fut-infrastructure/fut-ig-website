ValueSet: Facility Type Codes (Experimental)

Official URL: http://ehealth.sundhed.dk/vs/facility-type-codes Version: 10.0.1
Active as of 2019-02-08 Computable Name: FacilityTypeCodes

Allowed value set for healthcare facility type code represents the type of organizational setting of the clinical encounter during which the documented act occurred.
